# Artifact catalog

These directories contain acquired evidence, generated binary exports, and
checkpoint data. They are not all source material; consult each audit's
provenance fields.

| Directory | Contents |
| --- | --- |
| `audio_audit/` | Decentraland audio and channel-difference analysis |
| `bin/` | Binary exports generated by `solver.report` |
| `blockchain_cache/` | Cached transaction/block data used by nonce and provenance audits |
| `door_probe/` | Live/archived route probes; see `CLASSIFICATION.md` |
| `mitm_checkpoints/` | Chain 4 additive meet-in-the-middle checkpoints |
| `product_subset_checkpoints/` | Chain 4 product-family checkpoints |
| `xor_subset_checkpoints/` | Chain 4 XOR-subset checkpoints |
| `s91_direct_readability/` | S91 readability experiment outputs |
| `shared_wayback/` | Acquired shared Wayback material; see `INSPECTION.md` |
| `telegram_hints_pr16/` | Creator-hint screenshots, transcriptions, and git archaeology |
| `wayback_cache/` | Content-addressed archive cache and CDX responses |

Do not infer creator provenance from placement in this directory. Generated
candidate bytes under `bin/` are solver outputs unless the report explicitly
identifies an authenticated source.
