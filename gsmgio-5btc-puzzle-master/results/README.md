## Acceptance rules

A result is a prize match only if it satisfies an exact oracle:

- Half: full uncompressed public-key equality.
- Better Half: exact hash160 under a valid compressed or uncompressed
  serialization.
- Ciphertext: coherent plaintext plus an independent structural control.

PKCS#7 padding, English-looking fragments, address prefixes, or a convenient
32-byte slice are not acceptance criteria.

For the deduplicated outcome list, see
[`../../docs/ATTEMPT_LOG.md`](../../docs/ATTEMPT_LOG.md).
